# Critical-Vulnerabilities-Against-Major-Releases-of-LLMs
This project investigates if there is a corellation between the impact of the new LLM models being released, and the presence of critical vulnerabilities being reported.

<img width="960" height="540" alt="Critical Vulnerabilities Against Major Releases of LLMs" src="https://github.com/user-attachments/assets/bea661c9-572b-4c0e-bfae-db61ea78d4b8" />

To do so, it uses a Python script to scan available CVEs in a given range of publication dates. These dates are then aggregated into each month to create a trend which can be compared against known dates for common releases for popular LLMs.

A high number of vulnerabilities being reported around key release cycles could be indicative of increased efficiency at exposing vulnerabilities with available toolings.
